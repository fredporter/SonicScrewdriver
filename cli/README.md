# Sonic-Screwdriver Python CLI

Revival baseline: diagnostics, explicit state intake and offline library lookup. Python 3.11+; no Go toolchain.

Build with `python -m build`; install the resulting wheel.
Device and installer commands are reintroduced only after provider qualification.
Runtime state uses `UDOS_HOME` (default `~/Code/.udos`).
See the repository README and September revival/sprint documents for scope.
