## Redevelopment started — 11 September 2026

S1.2 first implementation: central absolute UDOS_HOME resolver, read-only
`sonic config paths`, and `sonic config import-legacy SOURCE` preview with
explicit `--apply`. Imports preserve originals, reject existing destinations,
symlinks and overlapping trees, and report file hashes and copied paths.
Spool now uses the shared resolver. Source tests: 24 passed on macOS.

Import intake is deliberately separate from activation: copied files go into
`sonic/imports/legacy`, not the active journal/library. This directory is owned
by Sonic, has no background service, consumes the selected source size, and can
be removed after inspection without affecting originals. Interrupted copies
can leave a partial intake; inspect/remove the intake before retrying. This is
not an atomic migration and must be run on trusted, quiescent local directories.
No installer should invoke it automatically.

S1.2 remains open for typed activation migrations and installed-artifact Linux
verification. Next: S1.3 validated library schemas and quarantining unverified
legacy specification/support claims, then S1.4 read-only discovery. Physical
write providers remain out of scope. This is redevelopment progress, not sprint
completion.

### S1.3 catalog foundation

Implemented strict version-1 catalog/model/provenance and capacity records,
initial instance/driver record shapes, duplicate-ID rejection, and offline
`sonic library search QUERY --json` / `sonic library show MODEL_ID`.
All 21 inherited models retain old specifications under `legacy_claims` with
source-file SHA-256 provenance. Active capacities remain unknown; all records
are unverified and cannot authorize flashing. No external specs were verified.
Removed the old package-data mutation API. Legacy identification now returns
all candidates, never the first fuzzy match as an identified physical device.

31 source tests passed before the compatibility cleanup; final test run below
covers that cleanup too. This read-only catalog adds no state or background
service; packaged seeds are versioned with Sonic and removed with the package.
It indexes model labels only, not the uKnowledge document collection.

Remaining S1.3 work: qualified source citations, hardware-ID matching contracts,
stronger instance/driver identity and timestamp validation, and driver/provenance
fixtures. S1.4 Linux scanner timeout/error/parser qualification remains next.
